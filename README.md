# 📖 SmartBudget – Mobile App UI/UX (Finance)

SmartBudget is a finance management app prototype designed to simplify expense tracking and reporting.  
It provides an intuitive onboarding flow, a clean dashboard, and interactive modules for managing personal finances.

---

## ✨ Features
- Onboarding screens with guided setup  
- Dashboard with expense summary  
- Add, edit, and delete expenses  
- Reports with charts and insights  
- Profile & settings management  
- Responsive UI for mobile and desktop  

---

## 🛠️ Tech Stack
- **Design**: Figma (UI/UX wireframes & prototypes)  
- **Frontend**: HTML, CSS (Flexbox/Grid), JavaScript  
- **Styling**: Bootstrap/Tailwind (optional for polish)  
- **Charts**: Chart.js / D3.js (planned for reports)
